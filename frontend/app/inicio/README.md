# Directorio: `app/inicio/`

Este directorio contiene la página principal del catálogo de la tienda WearLab (anteriormente ubicada en la raíz `/`).

## Contenido de la carpeta:
*   **`page.tsx`**: Renderiza el componente del Home Page incluyendo el banner principal (`Hero`), el buscador de la página principal (`SearchSection`), y la sección de productos recomendados (`Recommendations`).
