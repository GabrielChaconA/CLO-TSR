# Directorio: `src/types/`

Este directorio contiene las definiciones de tipos globales, interfaces y declaraciones de módulos adicionales de TypeScript.

## Ejemplos de uso:
*   Extender el objeto `Request` de Express para incluir los datos del usuario autenticado (ej: `req.user`).
*   Interfaces compartidas para estructuras de datos que se intercambian a lo largo de la aplicación.
