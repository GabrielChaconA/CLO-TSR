# Directorio: `src/config/`

Este directorio contendrá los archivos de configuración de la aplicación backend.

## Contenido de la carpeta:
*   **`env.ts`**: Carga y validación de variables de entorno (usando Zod) como `PORT`, `DATABASE_URL`, `JWT_SECRET`, etc.
*   Otras configuraciones de servicios de terceros (por ejemplo, integraciones con pasarelas de pago como Stripe o almacenamiento en la nube para diseños subidos).
