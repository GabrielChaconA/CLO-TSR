# Directorio: `src/routes/`

Este directorio define los endpoints (rutas) de la API REST de la aplicación, asociando cada ruta con sus respectivos validadores, middlewares de autenticación y controladores.

## Rutas a Definir:
*   **`/api/auth`** (`auth.routes.ts`): Endpoints para login, signup y logout.
*   **`/api/products`** (`products.routes.ts`): Endpoints para listar prendas, buscar y ver detalles de productos.
*   **`/api/designs`** (`designs.routes.ts`): Endpoints para subir, editar, borrar y publicar diseños.
*   **`/api/cart`** (`cart.routes.ts`): Endpoints para administrar el carrito de compras.
*   **`/api/checkout`** (`checkout.routes.ts`): Endpoints para gestionar las compras y procesar la pasarela de pagos.
